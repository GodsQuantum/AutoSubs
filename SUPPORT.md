# Support

Use GitHub Issues for reproducible bugs and focused feature requests.

Before filing a bug, include:

- AutoSubs version or container digest;
- FFmpeg version;
- installation type (Docker or development checkout);
- relevant redacted logs;
- whether the source/output path is local, NFS, CIFS/SMB, or another mount type;
- the encoder selected in Settings when the issue is render-related.

Do not post API keys, tokens, private filenames, private URLs or unredacted media metadata.

Security issues belong in a private vulnerability report, not a public issue. See [SECURITY.md](SECURITY.md).
