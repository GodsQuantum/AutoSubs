# AutoSubs v3.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans task-by-task with TDD.

**Goal:** Implement the approved AutoSubs v3.4 timing, preset, preview, brand, font and render UX redesign in an isolated development runtime without modifying production before validation.

**Architecture:** Persist one effective job configuration and one canonical timed-word timeline; make segmentation, preview and final libass rendering consume those same sources of truth. Add optional precision alignment behind a provider contract, deterministic brand overlays, a merged font catalog, server-rendered preview frames, render profiles and ETA while retaining the existing Rust/Svelte/Docker architecture.

**Tech Stack:** Rust 2024, Axum, SQLite/rusqlite, FFmpeg/libass, Svelte/Vite, existing OpenAI-compatible transcription API.

**Spec:** `docs/superpowers/specs/2026-10-07-autosubs-v3.4-timing-preview-brand-rendering-design.md`

## Global Constraints

- Work only in the isolated development runtime until DEV validation.
- Do not change established deployment mounts or production data/config.
- No production code without a failing regression test first.
- Preserve backward compatibility for persisted JSON/SQLite data with serde defaults/migrations.
- No mandatory permanent alignment sidecar.
- Preview and final render must share ASS, font resolution, geometry and visual FFmpeg/libass primitives.
- Do not push/merge/release until local and isolated DEV validation is green.
- Keep the future AppImage on the same backend/watcher architecture.

## Review Focus

- Manual imports with explicit presets must apply format, maxChars/maxLines and styling from one snapshot.
- Text/LLM corrections, punctuation, French elisions and hyphens must not detach display words from canonical timing.
- Missing fonts and ambiguous brand matches must fail visibly rather than silently substitute.
- Preview requests must be bounded/latest-wins and must not produce a different visual graph from final render.
- Render ETA/history must remain sane across encoder fallback and sparse history.
